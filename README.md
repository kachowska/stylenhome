# Style’n’Home — сайт дизайнера интерьеров

Статический сайт без зависимостей: шаблон + страницы + данные собираются в папку `dist/`.

```
node build.mjs                              # собрать сайт в dist/
python3 -m http.server 8080 -d dist         # посмотреть на http://localhost:8080
```

## Где что лежит

| Путь | Что это |
|---|---|
| `src/data/site.json` | Название, имя дизайнера, контакты, услуги, этапы работы |
| `src/data/projects.json` | Проекты портфолио (каждый проект = отдельная страница) |
| `src/pages/` | Содержимое страниц: главная, портфолио, услуги, о дизайнере, контакты |
| `src/layout.html` | Общая шапка и подвал |
| `src/assets/` | Стили, скрипт, фотографии |
| `docs/brief.md` | Бриф: вопросы заказчику и ответы |
| `references/` | Референсы и авторы временных фотографий |

## Что пока временное

- Все фотографии — с Unsplash, все проекты в `projects.json` помечены `"demo": true`.
- Имя дизайнера, телефон и почта — заглушки в `site.json`.
- Тексты (о дизайнере, услуги) — черновик, требуют проверки.
- Форма заявки открывает почтовую программу; отправки на сервер нет.
- Переключатель палитры в углу экрана — для выбора акцентного цвета, затем убрать.
