# Референсы: светлые сайты дизайнеров интерьера

Все сайты открыты и проверены 16.11.2026, скриншоты первого экрана лежат в `screens/`, общая доска — `board.jpg`.
По каждому напишите: нравится / не нравится и что именно (цвет, шрифт, сетка, подача фото, меню).

## Светлые

| № | Сайт | Что посмотреть |
|---|---|---|
| 1 | [Studio Kardum](https://www.studiokardum.com/) | Тёплый бежевый фон, тонкие линии-разделители, мелкий текст, фото на полэкрана. Очень спокойно и «дорого». |
| 2 | [Bureau EA](https://www.bureau-ea.com/) | Белый фон, крупный заголовок с засечками, одна синяя акцентная полоса, фильтр по типам проектов внизу. |
| 3 | [Niva Studio](https://www.niva-studio.com/) | Чистый белый, логотип по центру, горизонтальная лента фотографий. Минимум текста. |
| 4 | [Studio Jari](https://www.studiojari.com/) | Белый фон, логотип и меню по центру, один большой слайдер. Классическая «журнальная» подача. |
| 5 | [Amanda Shields Interiors](https://www.amandashieldsinteriors.com/) | Белый + бежевый, карусель фото, полное меню (услуги, портфолио, блог, магазин, заявка). Пример сайта «под заявки». |
| 6 | [Charlie Horner Design](https://charliehornerdesign.com/) | Предельный минимализм: почти пустой белый экран, маленький логотип, фото сбоку. |
| 7 | [Civilian](https://www.civilianprojects.com/) | Светло-жёлтый (сливочный) фон вместо белого, две колонки, вертикальный текст. Светлый, но с характером. |
| 8 | [Tyler Karu](https://tylerkaru.com/) | Белый фон, жирный современный логотип, горизонтальная прокрутка проектов. |
| 9 | [Sashya Thind](https://www.sashyathind.com/) | Светлая шапка с золотистым акцентом, слоган «Warm minimalism», полноэкранное фото с короткой фразой. |
| 10 | [Leanne Ford](https://www.leanneford.com/) | Белый фон и очень крупный чёрный логотип. Смелый, «личный бренд». |
