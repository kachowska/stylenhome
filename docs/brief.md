# Бриф: сайт дизайнера интерьера

Рабочий документ. Сначала — портрет дизайнера (заполняется по ответам), ниже — все вопросы.
Статусы: `[ ]` нет ответа · `[x]` ответ получен (ответ пишем сразу под вопросом).

Уже известно:
- Нравятся **светлые** дизайны.
- Рабочее название репозитория — `stylenhome` (это название бренда? — см. вопрос 1.2).

## Часть 2. Вопросы

### 1. О дизайнере
- [ ] 1.1 Сайт для вас лично или для другого человека / студии?
- [ ] 1.2 Имя и название бренда. `Style'n'Home` — это оно? Как пишется правильно?
- [ ] 1.3 Один дизайнер или команда (сколько человек, показываем ли их на сайте)?
- [ ] 1.4 Город и страна. В каких городах берёте проекты? Работаете ли удалённо?
- [ ] 1.5 Сколько лет опыта, какое образование, сколько реализованных проектов?
- [ ] 1.6 Есть ли публикации, награды, участие в выставках, ТВ-проектах?

### 2. Услуги и деньги
- [ ] 2.1 Полный список услуг (дизайн-проект, авторский надзор, комплектация, декорирование, консультация, 3D-визуализация, ремонт «под ключ» и т.д.).
- [ ] 2.2 Есть ли пакеты / тарифы? Показываем ли цены на сайте (точные, «от», или «по запросу»)?
- [ ] 2.3 Типы объектов: квартиры, дома, офисы, рестораны, магазины? Что приоритетно?
- [ ] 2.4 Минимальный метраж или бюджет, с которым работаете?
- [ ] 2.5 Как выглядит процесс работы по этапам и сколько длится проект?

### 3. Клиенты
- [ ] 3.1 Кто ваш идеальный клиент (возраст, семья, доход, тип жилья)?
- [ ] 3.2 С какими страхами и вопросами к вам чаще всего приходят?
- [ ] 3.3 Почему выбирают вас, а не другого дизайнера? (3 причины словами клиентов)
- [ ] 3.4 Откуда сейчас приходят клиенты?
- [ ] 3.5 Есть ли отзывы (текст, видео, скриншоты)? Можно ли публиковать имена и фото клиентов?

### 4. Портфолио
- [ ] 4.1 Сколько проектов готовы показать? Сколько из них — реализованные с фотосъёмкой, сколько — только 3D-визуализации?
- [ ] 4.2 Есть ли профессиональные фото? В каком качестве и где лежат (диск, ссылка)?
- [ ] 4.3 Что показываем по каждому проекту: метраж, город, срок, бюджет, задача клиента, планировки «до/после», чертежи?
- [ ] 4.4 Нужны ли фильтры (по типу помещения, стилю, метражу)?
- [ ] 4.5 Есть ли видео (рум-туры, процесс работы)?

### 5. Цели сайта
- [ ] 5.1 Главная цель: заявки, имидж / визитка, продажа консультаций, что-то ещё?
- [ ] 5.2 Главное действие посетителя: оставить заявку, написать в мессенджер, позвонить, записаться на консультацию, скачать прайс?
- [ ] 5.3 Куда должны приходить заявки (почта, Telegram, WhatsApp, CRM)?
- [ ] 5.4 Планируете ли рекламу на сайт (тогда нужны аналитика и посадочные страницы)?

### 6. Структура и функции
- [ ] 6.1 Одностраничный сайт или несколько страниц (Главная, Портфолио, Проект, Услуги, Обо мне, Контакты, Блог)?
- [ ] 6.2 Нужен ли блог / журнал?
- [ ] 6.3 Нужен ли калькулятор стоимости или квиз «рассчитать проект»?
- [ ] 6.4 Онлайн-запись на консультацию, онлайн-оплата — нужны?
- [ ] 6.5 Языки сайта (русский, английский, другие)?
- [ ] 6.6 Хотите сами добавлять проекты и править тексты (нужна админка) или будете обращаться ко мне?
- [ ] 6.7 Нужны ли раздел FAQ, страница для подрядчиков / партнёров, вакансии?

### 7. Визуальный стиль
- [ ] 7.1 Есть ли логотип, фирменные цвета, шрифты? Если нет — делаем на сайте с нуля?
- [ ] 7.2 Какой светлый вам ближе: чисто-белый, тёплый бежевый / молочный, светло-серый?
- [ ] 7.3 Акцентный цвет: нужен ли, и какой (терракота, оливковый, графит, золото)?
- [ ] 7.4 Шрифты: с засечками (элегантно, «журнально») или без (современно, строго)?
- [ ] 7.5 Анимации: спокойные и почти незаметные или эффектные?
- [ ] 7.6 Три слова, какое впечатление должен оставлять сайт.
- [ ] 7.7 Сайты, которые нравятся, и сайты, которые точно НЕ нравятся (любые, не только про интерьер).
- [ ] 7.8 Оценка референсов из `references/README.md`: что нравится, что нет и почему.

### 8. Тексты и контент
- [ ] 8.1 Есть ли готовые тексты (о себе, услуги) или пишу я по вашим ответам?
- [ ] 8.2 Есть ли ваши портретные фото для раздела «Обо мне»?
- [ ] 8.3 Контакты для сайта: телефон, почта, мессенджеры, соцсети, адрес офиса (если есть).

### 9. Техника и сроки
- [ ] 9.1 Есть ли домен и хостинг? Какой домен хотите?
- [ ] 9.2 Есть ли сейчас сайт? Что в нём нравится и что нет?
- [ ] 9.3 К какой дате нужен сайт? Есть ли привязка к событию?
- [ ] 9.4 Есть ли юридические требования (политика конфиденциальности, согласие на обработку данных, реквизиты ИП / компании)?
- [ ] 9.5 Конкуренты: 2–3 дизайнера или студии в вашем городе, с которыми вас сравнивают.
