# Утверждённая цветовая гамма

Утверждено заказчицей 18.11.2026 по макету главной страницы. Картинка с образцами — `preview/palette.png`.
В коде цвета заданы один раз, в начале файла `src/assets/css/style.css`.

| Цвет | Код | Имя в коде | Где используется |
|---|---|---|---|
| Тёплый бежевый | `#F3ECE1` | `--bg` | Основной фон страниц, шапка |
| Молочный | `#FAF6EF` | `--paper` | Светлые секции («Подход»), подвал, поля формы |
| Песочный | `#E8DCCB` | `--sand` | Акцентные секции («Пять шагов») |
| Тёмный шоколад | `#2A2520` | `--ink` | Текст, тёмный блок «Расскажите о вашем доме» |
| Аквамарин глубокий | `#24766F` | `--accent` | Кнопки, номера, ромбы, курсив в заголовках |
| Аквамарин светлый | `#5DB8AC` | `--accent-bright` | Орнамент-веер, мелкие акценты на тёмном фоне |
| Латунь | `#B08D62` | `--brass` | Рамки фотографий, уголки и линии ар-деко |
| Серо-коричневый | `#74685B` | `--muted` | Второстепенный текст |
| Линия | `#D6C8B3` | `--line` | Разделители и рамки полей |

## Правила

- Фон всегда светлый и тёплый; чисто-белый и чисто-чёрный не используются.
- Аквамарин — цвет действия: только кнопки, ссылки и небольшие акценты, не больше 5–10 % экрана.
- Латунь — цвет декора: тонкие линии, рамки, орнаменты. Текст латунью не набирается (мало контраста).
- Белый текст допустим только на аквамарине, тёмном шоколаде и поверх фотографий.

## Шрифты

- Заголовки: Cormorant Garamond (с засечками).
- Текст, меню, кнопки: Jost (геометрический, без засечек).
